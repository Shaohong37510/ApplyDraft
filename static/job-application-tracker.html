Frequently asked questions

Do I have to manually update the tracker?
No. Every application you generate with ApplyDraft is automatically logged with the firm name, position, date, and initial status. You can manually update the status as you hear back from firms.
Can I export my application history?
Yes. Your application tracker can be exported as a CSV file for use in Excel, Google Sheets, or any other tool.
What happens if I apply to the same firm twice?
ApplyDraft automatically detects duplicate applications and skips firms you've already applied to. This prevents the embarrassing situation of reaching out to the same company twice.
Can I use the tracker without using the AI cover letter generator?
The tracker is built into the ApplyDraft application workflow. It works best when used alongside the AI generation features, as it auto-populates based on your generated applications.
