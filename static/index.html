FAQ

Does ApplyDraft send emails automatically?
No. We only create drafts in your Gmail or Outlook inbox. You review each email before deciding to send — you stay in full control.
Can I use my own Claude API key?
Yes. You can connect your own Anthropic API key in Settings. This gives you more control over AI usage and costs.
What file types can I upload?
You can upload PDF, DOCX, and TXT files as attachments (resume, portfolio, etc.). Example files for AI analysis should be .txt or .pdf.
How personalized are the cover letters?
The AI researches each firm — their projects, design philosophy, and job requirements — before writing. Each cover letter is unique to that firm and position.
Do credits expire?
No, credits never expire. Buy once, use whenever you need.
Can I get a refund?
Unused credits are non-refundable once purchased. If you have an issue, please contact us at support@applydraft.top.
